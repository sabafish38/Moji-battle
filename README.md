# 消しバトNeo (Keshibato Neo)

> **〜 最大5文字の密着合体クラフト ＆ 本格物理消しゴムバトル 〜**
> 
> 日本の学校文化「消しゴム落とし（消しバト）」を、文字パーツの密着合体クラフトと本格物理シミュレーションによって進化させたWebブラウザゲームです。タクティカルかつ洗練されたジオメトリックUIとリアルな金属質感、10種類の個性的なバトルステージ、臨場感あふれるWeb Audio効果音を備えています。

---

## 主な特徴 (Features)

### 1. 最大5文字の「密着合体クラフト」システム
- **好きな文字を自由に合体**: キーボード入力やクイックパレットから好きな文字（漢字、英数、記号など）を選び、最大5文字まで密着合体させてオリジナル機体をビルド可能。
- **サブポリゴン・輪郭衝突判定**: 四角い外枠ではなく、文字の「ハネ・払い・角・凹凸」に沿ったリアルタイム輪郭判定を実装。文字のトゲで相手を引っ掛けたり、盾のような文字で受け流すなど、形状が物理挙動にダイレクトに反映されます。
- **リアルな金属マテリアル & 5大フォント書体**:
  - **マテリアル**: 鏡面クロム、チタン合金、鍛造ダマスカス鋼鉄、真鍮ブロンズ、重装メタル、超硬ブレード、黄金合金、サイバー発光、クラシック消しゴム
  - **フォント**: 重装角ゴシック、鋭角メカ明朝、ミリタリー極太、サイバー等幅、武神豪快筆

### 2. 個性豊かな 10種類のバトルステージ
ステージごとに異なる机の素材、摩擦係数、寸法、物理ギミックが用意されています。

1. **STAGE 01: スタンダード木製机** - 基礎性能と体幹が試される王道フィールド
2. **STAGE 02: 定規文房具ギミック机** - 外周アクリル定規による跳弾反射
3. **STAGE 03: ピンボールバンパー机** - 外郭バンパーと中央ターンテーブルによる弾丸バトル
4. **STAGE 04: 天王山・一本橋アリーナ** - 狭小橋と中央の制動高摩擦マット
5. **STAGE 05: 円形コロシアム机** - 全方位360度リングアウト判定の円盤闘技場
6. **STAGE 06: 十字路クロスアリーナ** - 4方向からの内向き加速板と交差点の旋回戦
7. **STAGE 07: ツイン浮島・超加速ハイウェイ** - 双方向加速板によるロケット正面衝突
8. **STAGE 08: 迷路ペンシルヘッジ** - 鉛筆バリケードが射線を区切る障害物迷路
9. **STAGE 09: 超低摩擦ガラステーブル** - 摩擦係数0.78の超滑走ドリフト＆グリップマット
10. **STAGE 10: 崩落縮小ボルケーノ** - ターン経過で机が毎ターン削られる灼熱サバイバル

### 3. 機体性能を活かす洗練されたギミック物理
- **加速板（Boost Pad）**: 機体の質量に反比例した慣性ブーストを付加。重戦車はどっしり進み、軽量機は電光石火のダッシュ。
- **回転板（Spin Pad）**: 機体のグリップ力に応じて回転に抵抗。姿勢角を変化させ、角での引っかけヒットを誘発。
- **高摩擦ゾーン（High-Friction Zone）**: 激突の勢いを適度に吸収する戦術的ブレーキマット。
- **10,000試合の大規模シミュレーション検証済**: 全ステージで消しゴム同士の激突によるKO率が**99.4%**を達成。ギミック任せではなく、プレイヤーのビルドとショットが勝敗を決します。

### 4. 進化した必殺技システム
- **吹っ飛び率10%毎のストックチャージ**: 被弾によって蓄積吹っ飛び率が10%増えるごとに必殺技ストックを+1獲得。
- **発射後〜完全停止までの任意タイミング発動**: 発射直後、直撃の瞬間、または机の端ギリギリで停止しそうな瞬間など、滑走中の**任意のタイミング**で発動可能。
  - **一刀両断（スラッシュ）**: 鋭角な斬り込み急加速
  - **神速加速（ブースト）**: 強力なロケットダッシュ
  - **絶対防御（アンカー）**: 空中急制動・落下防止グラウンドアンカー
  - **旋風渦潮（ボルテックス）**: 周囲の敵を遠心力で弾き飛ばす旋風
  - **破砕崩壊（バスター）**: 全周囲への強烈な衝撃波

### 5. スマホ横画面 ＆ タッチ操作完全対応 (Mobile Landscape Ready)
- **スマホ横画面（Landscape Viewport）完全最適化**:
  - 上下HUDバーを極限までスリム化し、画面の75%以上を広大なアリーナキャンバスとして確保。
  - 親指操作に配慮したコントロール配置と、iPhoneノッチ対応（Safe-Area Insets）。
  - 滑走中は**画面タップだけで即座に必殺技が発動**する快適なモバイル触感。
- **スマート待った（Undo） & 完全自動セーブ**:
  - CPU戦では思考開始前の手番冒頭までワンタップで完全巻き戻し可能。
  - LocalStorageによりリロードしても瞬時に直前の状態から再開。

## プレイ方法 (How to Play)

外部ライブラリや依存関係（npm等）は一切不要です。純粋な HTML5 + CSS3 + Vanilla JavaScript (Web Audio API) のみで構築されています。

### 1. ローカルで遊ぶ場合
1. このリポジトリをクローンまたはZIPダウンロードします。
   ```bash
   git clone https://github.com/YOUR_USERNAME/keshibato-neo.git
   ```
2. フォルダ内の `index.html` を任意のWebブラウザ（Google Chrome, Safari, Edge, Firefox等）で開くだけで即座にプレイできます。

### 2. GitHub Pages でオンライン公開する場合
1. GitHubの該当リポジトリの **Settings** > **Pages** を開きます。
2. **Branch** に `main`（または `master`）、フォルダに `/ (root)` を指定して **Save** を押します。
3. 数分後、発行されたURLにスマートフォンやPCからアクセスするだけで世界中どこからでも遊べます。

## 操作方法 (Controls)

| 操作 | PC (キーボード & マウス) | スマートフォン / タブレット (タッチ) |
|---|---|---|
| **ショット発射** | 机の上をドラッグして狙いを定め、離す | 画面をスワイプ（引っ張って離す） |
| **必殺技発動** | `[Space]` キー または スキルボタン | 滑走中に画面を1タップ または スキルボタン |
| **スピン回転選択** | `[1]` 前方推進 / `[2]` 標準 / `[3]` 後退 | 画面下のDRIVE / NORMAL / BACKボタンをタップ |
| **待った (Undo)** | `[Ctrl + Z]` または 画面下の UNDO ボタン | 画面下の UNDO ボタンをタップ |
| **機体改造・調整** | マウスドラッグ、ホイール拡大縮小、スライダー | タッチドラッグ、各種スライダー・タブ操作 |
